# The Blue Plate — Classic Chocolate Chip Cookies

A single-page recipe website built with semantic HTML5 and an external CSS stylesheet.

## Features

- Semantic structure: `header`, `nav`, `main`, `section`, `article`, `aside`, `figure`/`figcaption`, `blockquote`, `footer`
- Expository content (history and food science of the cookie) and persuasive content (three reasons to bake at home)
- Numbered step-by-step method with a 10-step list and baker's notes
- Responsive layout with a soft light-blue palette, a two-column recipe grid, and a mobile breakpoint
- Accessible: descriptive `alt` text, a skip link, visible keyboard focus, WCAG AA contrast, `prefers-reduced-motion` support
- Print stylesheet so the recipe can be printed cleanly
